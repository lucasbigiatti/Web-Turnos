# 🗓️ Sistema Web de Turnos para Consultorios

Este es un sistema web de turnos desarrollado con **Flask** (Python), diseñado para facilitar la gestión de turnos médicos o profesionales. Permite registrar pacientes, programar y modificar turnos, enviar recordatorios por correo electrónico y personalizar horarios de atención.

## 🚀 Funcionalidades principales

- 👤 Registro, edición y eliminación de pacientes
- 🗓️ Alta, modificación y cancelación de turnos
- 📧 Envío de recordatorios automáticos por correo electrónico (Flask-Mail)
- 🕒 Configuración de horarios del profesional
- 🔒 Gestión básica de usuarios (si fue implementada)
- 🧭 Navegación clara gracias a Jinja2 y rutas organizadas

## 🛠️ Tecnologías utilizadas

- **Python 3**
- **Flask**
- **Flask-Mail**
- **MySQL** + **mysql-connector-python**
- **HTML5** 
- **CSS**
